# CP BAR · Caja (app para la tablet)

App web instalable (PWA) de la caja CP BAR. Funciona sin internet una vez instalada.

**Abrir e instalar:** https://kaeldafae.github.io/bar-tpv-app/

Este repositorio solo contiene el programa, generado con `pwa/build.py` del repositorio
privado `bar-tpv` (no se edita aquí). Las ventas no están aquí: se guardan en la propia
tablet y sus copias de seguridad van a un repositorio privado.
